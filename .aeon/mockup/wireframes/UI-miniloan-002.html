รายการใบสมัครของฉัน

ให้ผู้สมัครเห็นภาพรวมใบสมัครทั้งหมดของตัวเองและเปิดดูรายละเอียดแต่ละใบ

visible to: ROLE-001 (ผู้สมัคร / เจ้าของบัญชี)

rows — sample row shows the bound column, not data
จำนวนเงินกู้ที่ขอสถานะวันที่ยื่นactions
ENT-001.requestedAmountENT-001.statusENT-001.submittedAt

states

empty
ยังไม่เคยยื่นใบสมัครเลย — แสดง "คุณยังไม่มีใบสมัคร" พร้อมปุ่มยื่นใบสมัครใหม่เด่นกลางหน้า
loading
แสดง skeleton/spinner ทับตำแหน่งข้อมูล ปุ่มที่ยิง action ถูกปิดใช้งานชั่วคราวระหว่างรอ
error
แสดงข้อความ "เกิดข้อผิดพลาด ลองใหม่อีกครั้ง" พร้อมปุ่มลองใหม่ ข้อมูลเดิมที่เคยโหลดสำเร็จยังคงอยู่บนจอ ไม่หายไป
unauthorized
แสดงข้อความ "คุณไม่มีสิทธิ์เข้าถึงหน้านี้" แทนข้อมูล ไม่แสดงแม้โครงหน้าที่ว่างเปล่า
overflow (does not occur)
ไม่เกิด — ผู้สมัครหนึ่งคนมีใบสมัครได้ไม่กี่ใบตามธรรมชาติของธุรกิจ ไม่มีเคสหลายพันรายการต่อคน
