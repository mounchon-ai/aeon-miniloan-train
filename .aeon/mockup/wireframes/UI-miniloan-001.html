กรอกและยื่นใบสมัครสินเชื่อ

ผู้สมัครกรอกข้อมูลใบสมัคร บันทึกเป็นร่าง และยื่นเมื่อกรอกครบ

visible to: ROLE-001 (ผู้สมัคร)

วงเงินอนุมัติสูงสุดโดยประมาณ
คำนวณจาก API ทุกครั้งที่รายได้เปลี่ยน ไม่ใช่ค่าที่ Web คำนวณเองตาม BR-miniloan-003@v1 และ BR-miniloan-027@v1

→ หน้ารายละเอียดใบสมัครของฉัน

states

empty (does not occur)
ไม่เกิด — ฟอร์มกรอกใหม่แสดงช่องว่างเปล่าเสมอ ไม่มีสถานะ empty แยกต่างหาก
loading
ระหว่างบันทึกร่างหรือยื่น ปุ่มที่กดถูก disable และแสดง spinner บนปุ่มนั้น ป้องกันกดซ้ำสองครั้งติดกันตาม BR-miniloan-043@v1
error
แสดงข้อความ error รายฟิลด์ใต้ช่องที่ผิด (เช่น จำนวนเงินกู้นอกช่วง) พร้อมคงข้อมูลที่กรอกไว้ทั้งหมด ไม่ล้างฟอร์ม
unauthorized (does not occur)
ไม่เกิด — ผู้สมัครที่ล็อกอินแล้วเข้าหน้านี้ได้เสมอเพื่อกรอกใบสมัครของตัวเอง
overflow (does not occur)
ไม่เกิด — ฟอร์มมีจำนวนฟิลด์คงที่ ไม่มีรายการที่ล้นจอ
