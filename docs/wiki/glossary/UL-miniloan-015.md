# UL-miniloan-015

## นิยาม
รายการขอแก้ไขข้อมูลของบัญชีสินเชื่อที่ปิดแล้ว (Closed) ต้องผ่านการอนุมัติจากผู้ถือบทบาทผู้อนุมัติ (UL-miniloan-016) ก่อนจึงมีผล ไม่ใช่การแก้ทับทันที · เก็บเป็นรายการปรับปรุงแยกจากตัวบัญชี ค่าเดิมของบัญชีคงไว้ไม่ถูกทับ และรายการเก็บค่าเดิม ค่าใหม่ ผู้ขอแก้ ผู้อนุมัติ และเวลาอนุมัติ

|---|---|
| คำไทย | การปรับปรุงบัญชีหลังปิด |
| ชื่อในระบบ | ClosedAccountAdjustment |
| เรียกอีกอย่างว่า | แก้ข้อมูลหลังปิดบัญชี · ปรับปรุงย้อนหลัง |
