# BR-miniloan-016@v1

## ข้อความของกฎ
งวดผ่อนเท่ากันทุกงวด (EMI) = P × r × (1+r)^n / ((1+r)^n − 1) โดย P = เงินต้น, r = อัตราดอกเบี้ยต่อเดือน (= อัตราต่อปี / 12), n = จำนวนงวด · แต่ละงวดแยกเป็นดอกเบี้ย (ยอดคงเหลือ × r) และเงินต้น (EMI − ดอกเบี้ย)

คำนวณตามสัญญา [CALC-miniloan-001@v1](../calculations/CALC-miniloan-001@v1.md)

## ที่มา

> "งวดผ่อนเท่ากันทุกงวด (EMI): `EMI = P × r × (1+r)^n / ((1+r)^n − 1)` · `P` = เงินต้น, `r` = อัตราดอกเบี้ยต่อเดือน (= อัตราต่อปี / 12), `n` = จำนวนงวด · แต่ละงวดแยกเป็นดอกเบี้ย (ยอดคงเหลือ × r) และเงินต้น (EMI − ดอกเบี้ย)"
> — [SRC-001](../sources/SRC-001.md) หน้า — §5 · BR-06
