# BR-miniloan-033@v1

## ข้อความของกฎ
Applicant เห็นและเรียกดูได้เฉพาะใบสมัครและบัญชีสินเชื่อที่ตัวเองเป็นเจ้าของเท่านั้น · ขอบเขตนี้ต้องถูกบังคับที่ฝั่ง API ไม่ใช่แค่ซ่อนบนหน้าจอ — เรียก API ด้วย id ของคนอื่นต้องถูกปฏิเสธ

## ที่มา

> "Applicant เห็นและเรียกดูได้เฉพาะใบสมัครและบัญชีสินเชื่อที่ตัวเองเป็นเจ้าของ"
> — [SRC-002](../sources/SRC-002.md) หน้า — §[4] QB-scope-01

> "**Given** บัญชี `Active` **When** เปิดดู **Then** เห็นตารางผ่อนทั้งหมดพร้อมสถานะแต่ละงวด (จ่ายแล้ว/ค้าง)"
> — [SRC-001](../sources/SRC-001.md) หน้า — §7 · US-09

## พิสูจน์โดย

- [EX-miniloan-136](../examples/EX-miniloan-136.md) — happy: เห็นครบทั้ง 2 ใบและ 1 บัญชีของตัวเองตามปกติ
- [EX-miniloan-137](../examples/EX-miniloan-137.md) — exception: API ปฏิเสธ — **"ไม่มีสิทธิ์เข้าถึงใบสมัครนี้"** · **การปฏิเสธเกิดที่ฝั่ง API ไม่ใช่แค่ไม่แสดงลิงก์บนหน้าจอ** — ถ้ากันแค่บนหน้าจอ ใบนี้จะผ่าน
- [EX-miniloan-138](../examples/EX-miniloan-138.md) — boundary: **ไม่มีใบของคนอื่นหลุดเข้ามาแม้แต่ใบเดียว** และจำนวนรายการที่ได้ตรงกับจำนวนใบของ ก. เท่านั้น · **ช่องโหว่ของขอบเขตข้อมูลมักอยู่ที่การเรียกแบบรายการ ไม่ใช่รายใบ** เพราะรายใบมักมีการตรวจ แต่รายการมักลืม
