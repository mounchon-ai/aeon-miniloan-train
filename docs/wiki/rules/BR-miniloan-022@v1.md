# BR-miniloan-022@v1

## ข้อความของกฎ
ยอดปิดบัญชีก่อนกำหนด = เงินต้นคงเหลือ + ดอกเบี้ยค้างจ่ายถึงวันที่ปิด + ค่าธรรมเนียมปิดก่อนกำหนด 1% ของเงินต้นคงเหลือ · ไม่คิดดอกเบี้ยของงวดในอนาคตที่ยังไม่ถึงกำหนด · ดอกเบี้ยค้างจ่ายใช้ฐานนับวัน actual/365 (นับวันจริง หารด้วย 365) นับจากวันครบกำหนดงวดล่าสุดที่ชำระแล้วถึงวันที่ปิด — ปิดตรงวันครบกำหนดที่เพิ่งชำระ ดอกเบี้ยค้างจ่ายเป็น 0

คำนวณตามสัญญา [CALC-miniloan-002@v1](../calculations/CALC-miniloan-002@v1.md)

## ที่มา

> "ยอดปิดบัญชี = เงินต้นคงเหลือ + ดอกเบี้ยค้างจ่ายถึงวันที่ปิด + ค่าธรรมเนียมปิดก่อนกำหนด (สมมติ 1% ของเงินต้นคงเหลือ) · ดอกเบี้ยของงวดในอนาคตที่ยังไม่ถึงกำหนด **ไม่คิด**"
> — [SRC-001](../sources/SRC-001.md) หน้า — §5 · BR-07

> "ดอกเบี้ยค้างจ่ายของยอดปิดบัญชีก่อนกำหนดใช้ฐานนับวัน actual/365 นับจากวันครบกำหนดงวดล่าสุดที่ชำระแล้วถึงวันที่ปิด"
> — [SRC-012](../sources/SRC-012.md) หน้า — §[1] Q-miniloan-004
