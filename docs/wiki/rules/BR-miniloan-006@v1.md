# BR-miniloan-006@v1

## ข้อความของกฎ
จัด Credit Band จากผลประเมิน: Band A = ผ่านทุกเกณฑ์ + DTI ≤ 50% → อนุมัติอัตโนมัติได้ (ยังต้องให้เจ้าหน้าที่ยืนยัน) · Band B = ผ่านเกณฑ์ + DTI มากกว่า 50% ถึง 70% → ส่งเจ้าหน้าที่พิจารณา · Band C = ผิดเกณฑ์ข้อใดข้อหนึ่ง → ปฏิเสธพร้อมเหตุผล · DTI เท่ากับ 50% พอดีได้ Band A ไม่ใช่ Band B — ขอบทั้งสองแบนด์ไม่ซ้อนกันอีกต่อไป

## ที่มา

> "Band A: ผ่านทุกเกณฑ์ + DTI ≤ 50% → **อนุมัติอัตโนมัติได้** (ยังต้องให้เจ้าหน้าที่ยืนยัน) · Band B: ผ่านเกณฑ์ + DTI 50–70% → **ส่งเจ้าหน้าที่พิจารณา** · Band C: ผิดเกณฑ์ข้อใดข้อหนึ่ง → **ปฏิเสธ** พร้อมเหตุผล"
> — [SRC-001](../sources/SRC-001.md) หน้า — §5 · BR-05

> "DTI เท่ากับ 50% พอดี ได้ Band A · อ่านตามเอกสารต้นทาง §7 US-06 ที่เขียน "DTI ≤ 50% → Band A" ซึ่งเครื่องหมาย ≤ นับรวม 50 พอดี"
> — [SRC-009](../sources/SRC-009.md) หน้า — §[3] Q-miniloan-003
