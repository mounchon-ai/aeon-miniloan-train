# BR-miniloan-002@v1

## ข้อความของกฎ
Debt-to-Income หลังรวมงวดใหม่ ต้อง ≤ 70% ของรายได้ต่อเดือน โดย DTI = (ภาระหนี้เดิมต่อเดือน + งวดใหม่) / รายได้ต่อเดือน · "งวดใหม่" คือค่างวด EMI ที่คำนวณด้วยสูตรเดียวกับ BR-miniloan-016@v1 จากจำนวนเงินกู้ที่ขอ จำนวนงวดที่ขอ และอัตราดอกเบี้ยที่มีผล ณ วันประเมิน — ไม่มีสูตรประมาณแยกอีกชุด · DTI คำนวณครั้งเดียวตอนยื่นจากจำนวนเงินกู้ที่ขอ และไม่คำนวณใหม่แม้เจ้าหน้าที่จะปรับวงเงินลงตาม BR-miniloan-012@v1

## ที่มา

> "Debt-to-Income หลังรวมงวดใหม่ ต้อง ≤ 70% ของรายได้ต่อเดือน · สูตร: `DTI = (ภาระหนี้เดิมต่อเดือน + งวดใหม่โดยประมาณ) / รายได้ต่อเดือน`"
> — [SRC-001](../sources/SRC-001.md) หน้า — §5 · BR-02

> "งวดใหม่โดยประมาณ คือ EMI ตาม BR-miniloan-016@v1 คำนวณจากจำนวนเงินกู้ที่ขอ จำนวนงวดที่ขอ และอัตราดอกเบี้ยที่มีผล ณ วันประเมิน — ใช้สูตรเดียวกับที่สร้างตารางผ่อนจริง ไม่มีสูตรประมาณแยกอีกชุด"
> — [SRC-009](../sources/SRC-009.md) หน้า — §[1] Q-miniloan-001

> "DTI คิดจากจำนวนเงินกู้ที่ขอ ครั้งเดียวตอนยื่น ไม่คำนวณใหม่แม้เจ้าหน้าที่จะปรับวงเงินลง"
> — [SRC-009](../sources/SRC-009.md) หน้า — §[2] Q-miniloan-002

## พิสูจน์โดย

- [EX-miniloan-037](../examples/EX-miniloan-037.md) — boundary: ผ่านเกณฑ์ DTI — หน้าผลการประเมินแสดง "ภาระหนี้ต่อรายได้ (DTI) 70.00% ✓ (เกณฑ์ ไม่เกิน 70%)" · ค่าที่ตรงเพดานพอดีถือว่าผ่าน ไม่ใช่ตก
- [EX-miniloan-038](../examples/EX-miniloan-038.md) — exception: ไม่ผ่านเกณฑ์ DTI — หน้าผลการประเมินแสดง "ภาระหนี้ต่อรายได้ (DTI) เกินเกณฑ์ ✗ ภาระหนี้รวม 21,001 บาท เกินเพดาน 21,000 บาท (70% ของรายได้ 30,000 บาท/เดือน)" และใบสมัครได้ Band C ตาม BR-miniloan-006@v1 · **การเปรียบเทียบต้องตัดสินจากยอดบาทที่เกินจริง ไม่ใช่จากเปอร์เซ็นต์ที่ปัดแล้ว** — 21,001 ÷ 30,000 ปัดสองตำแหน่งได้ 70.00% เท่ากับเคสที่ผ่าน
- [EX-miniloan-039](../examples/EX-miniloan-039.md) — happy: ผ่านเกณฑ์ DTI — "ภาระหนี้ต่อรายได้ (DTI) 35.00% ✓ (เกณฑ์ ไม่เกิน 70%)"
- [EX-miniloan-040](../examples/EX-miniloan-040.md) — alternate: ค่า DTI ในผลการประเมิน **ไม่เปลี่ยน** ยังเป็นค่าเดิมที่คำนวณจากยอดที่ขอ 300,000 บาท · หน้าจอกำกับว่า "DTI คำนวณจากจำนวนเงินกู้ที่ขอ 300,000 บาท ณ วันยื่น" เพื่อไม่ให้เข้าใจผิดว่าเป็นค่าของวงเงินที่อนุมัติจริง
