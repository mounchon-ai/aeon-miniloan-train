# BR-miniloan-007@v1

## ข้อความของกฎ
ยื่นใบสมัครได้เฉพาะเมื่อกรอกครบ (ชื่อ อายุ รายได้ อายุงาน จำนวนเงินกู้ จำนวนงวด) — ครบแล้วสถานะเปลี่ยนเป็น Submitted และล็อกการแก้ไข · ไม่ครบ ระบบต้องปฏิเสธพร้อมระบุ field ที่ขาด และคงสถานะ Draft

## ที่มา

> "**Given** ใบสมัครกรอกครบ (ชื่อ อายุ รายได้ อายุงาน จำนวนเงินกู้ จำนวนงวด) **When** กดยื่น **Then** สถานะเปลี่ยนเป็น `Submitted` และล็อกการแก้ไข"
> — [SRC-001](../sources/SRC-001.md) หน้า — §7 · US-02

## พิสูจน์โดย

- [EX-miniloan-029](../examples/EX-miniloan-029.md) — happy: ใบสมัครเปลี่ยนสถานะเป็น "ยื่นแล้ว (Submitted)" และหน้าจอแสดง "ยื่นใบสมัครเรียบร้อย — แก้ไขข้อมูลไม่ได้อีก" · ทุกช่องกรอกกลายเป็นอ่านอย่างเดียว
- [EX-miniloan-030](../examples/EX-miniloan-030.md) — exception: ระบบไม่เปลี่ยนสถานะ และแสดงข้อความระบุช่องที่ขาด **ครบทุกช่อง ไม่ใช่ช่องแรกช่องเดียว** — "ยื่นใบสมัครไม่ได้ — ยังกรอกไม่ครบ: อายุงาน, จำนวนงวด" · ใบสมัครยังเป็น "ร่าง (Draft)" และยังแก้ไขได้ตามปกติ
- [EX-miniloan-031](../examples/EX-miniloan-031.md) — boundary: ทั้งสองทางถูกปฏิเสธเหมือนกัน — "ใบสมัครนี้ยื่นแล้ว แก้ไขข้อมูลไม่ได้" และ API ปฏิเสธด้วยตาม BR-miniloan-025@v1 · จำนวนเงินกู้ยังเป็นค่าเดิม
