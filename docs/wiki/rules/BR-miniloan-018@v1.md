# BR-miniloan-018@v1

## ข้อความของกฎ
เจ้าของบัญชีเปิดดูตารางผ่อนของบัญชีสถานะ Active ของตัวเองได้ทั้งตาราง พร้อมสถานะรายงวด (จ่ายแล้ว / ค้าง)

## ที่มา

> "**Given** บัญชี `Active` **When** เปิดดู **Then** เห็นตารางผ่อนทั้งหมดพร้อมสถานะแต่ละงวด (จ่ายแล้ว/ค้าง)"
> — [SRC-001](../sources/SRC-001.md) หน้า — §7 · US-09

## พิสูจน์โดย

- [EX-miniloan-099](../examples/EX-miniloan-099.md) — happy: เห็น **ทุกงวดตั้งแต่งวดที่ 1 ถึงงวดสุดท้าย ไม่ใช่เฉพาะงวดที่ยังไม่ถึงกำหนด** · แต่ละงวดมีป้ายสถานะ **"จ่ายแล้ว"** หรือ **"ค้าง"** กำกับชัดเจน · เห็นเงินต้น ดอกเบี้ย และยอดคงเหลือของแต่ละงวด
- [EX-miniloan-100](../examples/EX-miniloan-100.md) — exception: ทั้งสองทางถูกปฏิเสธ — **"ไม่มีสิทธิ์เข้าถึงบัญชีสินเชื่อนี้"** · การปฏิเสธเกิดที่ฝั่ง API ตาม BR-miniloan-033@v1 ไม่ใช่แค่ไม่แสดงลิงก์บนหน้าจอ · **ไม่มีข้อมูลงวดใดของ ข. หลุดออกมาแม้แต่แถวเดียว**
