> บันทึกคำตอบจากรอบ /req:calc BR-miniloan-022@v1 (2026-09-01) — พี่ปูเป็นผู้ตัดสิน ทุกข้อเลือกตัวเลือกที่ระบบเสนอไว้ (ดาว) [1] ยืนยันสูตรและ inputs ตามร่าง → **ตามดาว** — สูตร: ยอดปิดบัญชีก่อนกำหนด = เงินต้นคงเหลือ + ดอกเบี้ยค้างจ่าย + ค่าธรรมเนียมปิดก่อนกำหนด · ค่าธรรมเนียม = เงินต้นคงเหลือ × 1% · ดอกเบี้ยค้างจ่าย = เงินต้นคงเหลือ × อัตราดอกเบี้ยต่อปี × จำนวนวัน / 365 · จำนวนวัน = วันที่ปิดบัญชี − วันครบกำหนดงวดล่าสุดที่ชำระแล้ว · 1% และ 365 เป็นค่าคงที่ในสูตร ไม่ใช่ input แยก · inputs: remaining_principal money(2) (จากคอลัมน์ตารางผ่อนฉบับล่าสุดตาม BR-miniloan-053@v1) · annual_rate rate(10) (เวอร์ชันที่ผูกกับบัญชีตอนสร้างตารางตาม BR-miniloan-037@v1) · last_paid_due_date date · closing_date date [2] numeric_type → **decimal (ตามดาว)** [3] rounding_mode → **HALF_UP (ตามดาว)** สอดคล้องกับ BR-miniloan-035@v1 [4] rounding_points → **ตามดาว** — ปัดที่บรรทัดดอกเบี้ยค้างจ่ายและบรรทัดค่าธรรมเนียมเป็นค่าเดียวแต่ละบรรทัด (2 ตำแหน่ง) · เงินต้นคงเหลือเป็นค่าที่ปัดมาแล้วจากตารางผ่อน อ่านตรงๆไม่ปัดซ้ำ · ผลรวมทั้งสามไม่ปัดซ้ำเพราะทุกตัวเป็น 2 ตำแหน่งอยู่แล้ว [5] residual_policy → **ไม่มี — null (ตามดาว)** ยอดครั้งเดียว ไม่ใช่ตารางผ่อนที่มีงวดสุดท้ายดูดเศษ [6] วันที่ปิดบัญชีย้อนหลัง (ก่อนวันครบกำหนดงวดล่าสุดที่ชำระแล้ว) → **ปฏิเสธ input ทันที (ตามดาว)** ไม่คำนวณต่อ ไม่คืนค่าติดลบ [7] ยังไม่มีงวดไหนถูกชำระเลย (ขอยอดก่อนงวดแรกถึงกำหนด) → last_paid_due_date อ้างอิง **วันเบิกจ่ายของบัญชี (ตามดาว)**
