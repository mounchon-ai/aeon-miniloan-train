## ที่สกัดออกมา (markdown-text)

> ## 5. กฎธุรกิจ (Business Rules) — ค่าสมมติทั้งหมด BR-01 คุณสมบัติผู้สมัคร - อายุ 20–60 ปี - รายได้ต่อเดือน ≥ 15,000 บาท - อายุงานปัจจุบัน ≥ 4 เดือน BR-02 ความสามารถในการชำระ (DTI) - Debt-to-Income หลังรวมงวดใหม่ ต้อง ≤ 70% ของรายได้ต่อเดือน - สูตร: DTI = (ภาระหนี้เดิมต่อเดือน + งวดใหม่โดยประมาณ) / รายได้ต่อเดือน BR-03 วงเงินสูงสุด - วงเงินอนุมัติสูงสุด = 5 เท่าของรายได้ต่อเดือน และไม่เกิน 1,000,000 บาท BR-04 เงื่อนไขสินเชื่อ - จำนวนเงินกู้: 10,000 – 1,000,000 บาท - จำนวนงวด: 6 – 60 งวด (รายเดือน) - อัตราดอกเบี้ย: แบบลดต้นลดดอก 25% ต่อปี (สมมติ ภายใต้เพดานที่กฎหมายกำหนด) BR-05 การให้คะแนน (Credit Band — สมมติ) - Band A: ผ่านทุกเกณฑ์ + DTI ≤ 50% → อนุมัติอัตโนมัติได้ (ยังต้องให้เจ้าหน้าที่ยืนยัน) - Band B: ผ่านเกณฑ์ + DTI 50–70% → ส่งเจ้าหน้าที่พิจารณา - Band C: ผิดเกณฑ์ข้อใดข้อหนึ่ง → ปฏิเสธ พร้อมเหตุผล BR-06 การคำนวณงวดผ่อน (Amortization) - งวดผ่อนเท่ากันทุกงวด (EMI): EMI = P × r × (1+r)^n / ((1+r)^n − 1)   - P = เงินต้น, r = อัตราดอกเบี้ยต่อเดือน (= อัตราต่อปี / 12), n = จำนวนงวด - แต่ละงวดแยกเป็นดอกเบี้ย (ยอดคงเหลือ × r) และเงินต้น (EMI − ดอกเบี้ย) - งวดสุดท้ายปัดเศษให้ยอดคงเหลือเป็น 0 พอดี BR-07 การปิดก่อนกำหนด (Early Settlement) - ยอดปิดบัญชี = เงินต้นคงเหลือ + ดอกเบี้ยค้างจ่ายถึงวันที่ปิด + ค่าธรรมเนียมปิดก่อนกำหนด (สมมติ 1% ของเงินต้นคงเหลือ) - ดอกเบี้ยของงวดในอนาคตที่ยังไม่ถึงกำหนด ไม่คิด ## 6. วงจรสถานะ (State Machine) LoanApplication Draft → Submitted → UnderReview → Approved → Disbursed                          └──────→ Rejected - เปลี่ยนสถานะได้ผ่าน method บน Aggregate เท่านั้น (เช่น Submit(), Approve(), Reject(), Disburse()) - Disburse() สร้าง LoanAccount ใหม่ LoanAccount Active → Closed - ปิดได้เมื่อชำระครบทุกงวด หรือปิดก่อนกำหนดสำเร็จ
