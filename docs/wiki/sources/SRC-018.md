สกัดตรงจาก SRC-001 §5 BR-02 + SRC-009 (คำตอบ Q-miniloan-001/002 ที่มีอยู่แล้ว) — ไม่ต้องถามใหม่ เพราะเอกสารตอบไว้ครบแล้วว่า "งวดใหม่โดยประมาณ" คือ EMI ตามสูตรเดียวกับ BR-miniloan-016@v1
