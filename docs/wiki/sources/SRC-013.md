## เนื้อความ

> บันทึกรอบตอบการ์ดแดง Q-miniloan-006 / Q-miniloan-012 / Q-miniloan-013 (2026-08-15) — เจ้าของสเปกตอบในแชท รอบนี้ยิงคำถามจากการ์ดแดงที่เปิดค้างอยู่ ไม่ได้ยิงจากคลังคำถาม จึงไม่มี QB id และไม่มี ⭐ พรีเซ็ต — ผู้ถามระบุไว้ในรอบว่าติดดาวไม่ได้เพราะการ์ดแดงคือสิ่งที่ยังไม่มีใครตัดสิน บอกได้แค่ว่าตัวเลือกไหนถูกกฎที่ตกลงไปแล้วตัดออก คำตอบดิบที่เจ้าของพิมพ์: "1ก a ,1ข a,2ก b,2ข -,3ก a,3ข a" [1] Q-miniloan-006 · REQ-miniloan-003 · จาก BR-miniloan-036@v1 (อัตราดอกเบี้ยมีเวอร์ชันและวันเริ่มมีผล)   1ก) เบิกจ่าย *ตรงวัน* effective date พอดี ใช้อัตราไหน       a) ใช้อัตราใหม่ — วันเริ่มมีผลนับรวมวันนั้น (inclusive)       b) ใช้อัตราเก่า — อัตราใหม่เริ่มมีผลวันถัดไป (exclusive)       c) ยังไม่แน่ใจ / ต้องถามลูกค้า       → ตอบ a : ใช้อัตราใหม่ วันเริ่มมีผลนับรวมวันนั้น   1ข) ประกาศอัตราย้อนหลัง (effective date เป็นวันในอดีต) ทำได้ไหม       a) ทำไม่ได้ — effective date ต้องเป็นวันที่ประกาศหรือวันในอนาคตเท่านั้น ใส่วันในอดีตระบบปฏิเสธ       b) ทำได้ แต่ไม่กระทบบัญชีที่เบิกจ่ายไปแล้ว — ตารางผ่อนเดิมคงเดิมทุกกรณี       c) ทำได้ และบัญชีที่เบิกจ่ายในช่วงย้อนหลังต้องคำนวณตารางผ่อนใหม่ — ถูกตัดออกไปก่อนถามแล้ว เพราะขัด BR-miniloan-036@v1 และ BR-miniloan-037@v1       d) ยังไม่แน่ใจ / ต้องถามลูกค้า       → ตอบ a : ประกาศย้อนหลังไม่ได้ ระบบต้องปฏิเสธ effective date ที่เป็นวันในอดีต [2] Q-miniloan-012 · REQ-miniloan-002 · จาก BR-miniloan-031@v1 (สิทธิ์เดินสถานะใบสมัคร)   2ก) ใบที่ยังไม่ถูกมอบหมาย (Draft, Submitted) ใครยกเลิกได้       a) Loan Officer คนไหนก็ได้       b) เฉพาะหัวหน้าเจ้าหน้าที่สินเชื่อ (UL-miniloan-019) เท่านั้น       c) ยกเลิกไม่ได้จริงจนกว่าจะถูกมอบหมาย       d) ยังไม่แน่ใจ / ต้องถามลูกค้า       → ตอบ b : เฉพาะหัวหน้าเจ้าหน้าที่สินเชื่อเท่านั้น   2ข) (ตอบเฉพาะเมื่อ 2ก = c) เส้น Draft → Cancelled และ Submitted → Cancelled เอายังไง       → ไม่ตอบ ไม่เข้าเงื่อนไข เพราะ 2ก = b · เส้นทั้งสองยังคงอยู่ใน BR-miniloan-010@v1 ตามเดิม   หมายเหตุของรอบ: คำตอบ b ยังแปลงเป็นกฎไม่ได้ในรอบนี้ เพราะ BR-miniloan-031@v1 เขียนไว้ว่า "การยกเลิก (→ Cancelled) ทำได้เฉพาะ Loan Officer เท่านั้น" และ UL-miniloan-019 นิยามหัวหน้าเป็น actor ที่เอกสารต้นทาง §3 ไม่มี — ยังไม่ตัดสินว่าหัวหน้าเป็น Loan Officer คนหนึ่งหรือเป็น actor แยก · REQ-miniloan-002 จึงถูกแช่ไว้ในรอบนี้ ยังไม่เขียนกฎใด และ Q-miniloan-012 ยังเปิดอยู่ [3] Q-miniloan-013 · REQ-miniloan-004 · จาก BR-miniloan-046@v1 (โปะเงินต้น)   3ก) ค่าธรรมเนียมโปะ 1% ของยอดส่วนที่เกิน เก็บยังไง       a) หักจากส่วนเกินก่อนนำไปตัดเงินต้น — เงินต้นลดลง = ส่วนเกิน × 99% เงินเข้าก้อนเดียว ไม่มีรายการเรียกเก็บแยก       b) เก็บเพิ่มจากผู้กู้ต่างหาก — เงินต้นลดลงเต็มส่วนเกิน       c) ยังไม่แน่ใจ / ต้องถามลูกค้า       → ตอบ a : หักจากส่วนเกินก่อนนำไปตัดเงินต้น   3ข) ถ้าส่วนเกินมากพอปิดบัญชีได้พอดีในครั้งเดียว คิดค่าธรรมเนียมฐานไหน       a) ถือเป็นการปิดบัญชีก่อนกำหนด ใช้ BR-miniloan-022@v1 เสมอ (1% ของเงินต้นคงเหลือ)       b) ยังถือเป็นการโปะ ใช้ BR-miniloan-046@v1 เสมอ (1% ของส่วนเกิน)       c) ให้ผู้ใช้หรือเจ้าหน้าที่เลือกฐานเอง — ถูกตัดออกไปก่อนถามแล้ว โดยข้อความของ Q-miniloan-013 เอง ("ต้องไม่เหลือช่องให้เลือกทางที่ถูกกว่าได้เอง")       d) ยังไม่แน่ใจ / ต้องถามลูกค้า       → ตอบ a : ถือเป็นการปิดบัญชีก่อนกำหนด ใช้ฐาน BR-miniloan-022@v1 และระบบตัดสินเอง
