# CALC-miniloan-002@v1

## สูตร

```
DTI = (ภาระหนี้เดิมต่อเดือน + งวดใหม่โดยประมาณ) / รายได้ต่อเดือน · เกณฑ์ผ่าน: DTI ≤ 0.70 (70%) · งวดใหม่โดยประมาณ = ค่างวดที่แสดง (round(EMI,2) ตาม CALC-miniloan-001@v2) คำนวณจากจำนวนเงินกู้ที่ขอ (ไม่ใช่ยอดอนุมัติ) จำนวนงวดที่ขอ และอัตราดอกเบี้ยที่มีผล ณ วันประเมิน — ไม่มีสูตรประมาณแยกอีกชุด · คำนวณครั้งเดียวตอนยื่น ไม่คำนวณใหม่แม้เจ้าหน้าที่จะปรับวงเงินลงตาม BR-miniloan-012@v1
```

ผูกกับกฎ [BR-miniloan-002@v1](../rules/BR-miniloan-002@v1.md)

## พฤติกรรมที่ขอบ

- DTI = 70.00% พอดี (เท่ากับเพดานเป๊ะ) → ผ่านเกณฑ์ ไม่ใช่ตก (ตาม EX-miniloan-037 ที่ยืนยันแล้ว) — เพราะกฎเขียนว่า ≤ 70% ไม่ใช่ < 70%
- รายได้ต่อเดือนต่ำกว่า 15,000 บาท → ไม่ถึงสัญญานี้ ถูกกรองไปแล้วโดย BR-miniloan-001@v1 ก่อนถึงขั้นประเมิน DTI
- จำนวนเงินกู้ที่ขอหรือจำนวนงวดนอกช่วง 10,000–1,000,000 บาท / 6–60 งวด → ไม่ถึงสัญญานี้เช่นกัน เป็นด่านของ BR-miniloan-004@v1
- อัตราดอกเบี้ย 0% ต่อปี → งวดใหม่ใช้ EMI = P/n ตาม boundary ของ CALC-miniloan-001@v2 เอง สัญญานี้ไม่ต้องนิยามซ้ำ เพราะรับค่างวดที่คำนวณมาแล้วเป็นอินพุตเดียว
