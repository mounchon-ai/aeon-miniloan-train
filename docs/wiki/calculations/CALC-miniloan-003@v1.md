# CALC-miniloan-003@v1

## สูตร

```
วงเงินอนุมัติสูงสุด (MaxApprovableAmount) = MIN(5 × รายได้ต่อเดือน, 1,000,000 บาท) — 5 เท่าของรายได้ หรือ 1,000,000 บาท แล้วแต่ค่าไหนน้อยกว่า
```

ผูกกับกฎ [BR-miniloan-003@v1](../rules/BR-miniloan-003@v1.md)

## ตัวแปรเข้า

| ชื่อ | ชนิด | ความหมาย |
|---|---|---|
| `monthly_income` | money(2) | รายได้ต่อเดือนของผู้สมัคร — ต้อง ≥ 15,000 บาทตาม BR-miniloan-001@v1 (การกรองเป็นหน้าที่ของกฎข้อนั้น ไม่ใช่ของสัญญานี้) |

## การปัดเศษ — ส่วนที่ทำให้ตัวเลขต่างกันได้ทั้งที่สูตรเหมือนกัน

| เรื่อง | ค่า |
|---|---|
| ชนิดตัวเลข | decimal |
| วิธีปัด | HALF_UP |
| ปัดตรงไหน | ไม่มีจุดที่ต้องปัดจริงในทางปฏิบัติ — ตัวคูณ (5) เป็นจำนวนเต็ม เงิน money(2) คูณด้วยจำนวนเต็มยังคงมี 2 ตำแหน่งทศนิยมพอดีเสมอ ไม่มีเศษเกิดขึ้น · เพดาน 1,000,000.00 บาทก็มี 2 ตำแหน่งอยู่แล้ว การเทียบ MIN จึงไม่มีจุดปัดเช่นกัน · ระบุ HALF_UP ไว้เพื่อความสอดคล้องกับสัญญาอื่นในระบบ เผื่อกรณีในอนาคตที่ตัวคูณไม่ใช่จำนวนเต็ม |
| เศษที่เหลือ | — |

## พฤติกรรมที่ขอบ

- รายได้ 199,999 บาท → 5×199,999 = 999,995 บาท (ต่ำกว่าเพดาน 5 บาท) → ใช้ค่าจากสูตร (EX-miniloan-020)
- รายได้ 200,000 บาทพอดี → 5×200,000 = 1,000,000 บาทพอดี → สูตรกับเพดานให้คำตอบตรงกัน เป็นจุดที่เขียนเงื่อนไขผิดด้าน (< แทน ≤ หรือกลับกัน) จะพลาด (EX-miniloan-021)
- รายได้ 250,000 บาท → 5×250,000 = 1,250,000 บาท เกินเพดาน → ใช้เพดาน 1,000,000 บาท และต้องระบุว่าเพดานเป็นตัวจำกัด ไม่ใช่สูตร ตาม BR-miniloan-009@v1 (EX-miniloan-022)
- รายได้ต่ำกว่า 15,000 บาท → ไม่ถึงสัญญานี้ ถูกกรองโดย BR-miniloan-001@v1 ก่อนแล้ว
