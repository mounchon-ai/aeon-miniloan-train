# DQ-miniloan-003

## คำถามที่เลื่อนไป
ถ้ามอบหมายใบสมัครใหม่ให้เจ้าหน้าที่คนอื่น คนเดิมยังเห็นใบสมัครนั้นอยู่ไหม — และประวัติการมอบหมายต้องเก็บไว้หรือทับของเดิม

## คำตอบ
