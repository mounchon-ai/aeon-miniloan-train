# Q-miniloan-008

## การ์ดแดง
BR-miniloan-038@v1 บอกว่าแก้ข้อมูลบัญชีที่ปิดแล้วต้องมีคนอนุมัติ แต่ยังไม่มีใครตอบว่า **ใครเป็นผู้อนุมัติ** — Loan Officer คนไหนก็ได้ที่ไม่ใช่คนแก้ · หัวหน้า · หรือกำหนด role เองได้ · และถ้ายังไม่มีใครถูกกำหนดเป็นผู้อนุมัติ ระบบทำยังไง (ปิดฟีเจอร์นี้ หรือมี default) — เป็นคำถามที่หมวด approval ชั้น 2 ถามตรงๆ อยู่แล้ว

## คำตอบ
ผู้อนุมัติกำหนดเป็น role ที่ตั้งค่าได้ในระบบ ไม่ fix ในโค้ด (QB-apr-01 → c → BR-miniloan-039@v1) · ถ้ายังไม่ได้ตั้ง role ผู้อนุมัติ ฟีเจอร์แก้ข้อมูลบัญชีที่ปิดแล้วใช้ไม่ได้เลย ไม่มีค่า default (QB-apr-02 → c → BR-miniloan-040@v1) · ส่วนที่ยังเปิดอยู่ — ใครตั้งค่า role นี้ได้ และผู้อนุมัติต้องต่างจากผู้ขอแก้หรือไม่ — แยกไปเป็น Q-miniloan-009
