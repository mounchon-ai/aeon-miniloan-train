# Q-miniloan-010

## การ์ดแดง
BR-miniloan-046@v1 ให้ส่วนที่ชำระเกินไปตัดเงินต้น แต่ยังไม่มีใครตอบสองข้อที่เขียนโค้ดไม่ได้ถ้าไม่รู้: (1) **โปะแล้วลดอะไร** — จำนวนงวดสั้นลงโดยค่างวดเท่าเดิม หรือค่างวดถูกลงโดยจำนวนงวดเท่าเดิม · เป็นการตัดสินทางธุรกิจที่ให้ตารางผ่อนฉบับใหม่คนละหน้าตากันสิ้นเชิง และ BR-miniloan-016@v1 คำนวณ EMI จาก n ซึ่งเปลี่ยนไปคนละทางในสองคำตอบนี้ · (2) **การโปะมีค่าธรรมเนียมไหม** — BR-miniloan-022@v1 คิดค่าธรรมเนียมปิดก่อนกำหนด 1% ของเงินต้นคงเหลือ · การโปะบางส่วนคิดแบบเดียวกัน คิดอัตราอื่น หรือไม่คิดเลย · ถ้าไม่คิด ผู้กู้โปะทีละน้อยจนเกือบหมดแล้วค่อยปิดบัญชี จะเสียค่าธรรมเนียมน้อยกว่าปิดทีเดียวมาก
