# EX-miniloan-012

## กำหนดให้ (given)
บัญชีสินเชื่อสถานะ Active ที่ชำระมาแล้ว 2 งวด และงวดที่ 3 เป็นงวดค้างงวดถัดไป — ขอบที่ตรวจคือค่าที่ต่ำกว่ายอดงวดน้อยที่สุดเท่าที่เป็นไปได้

## เมื่อ (when)
Operations บันทึกการชำระงวดที่ 3 ด้วยยอดที่น้อยกว่ายอดงวดอยู่ 0.01 บาท

## แล้ว (then)
ระบบไม่บันทึกการชำระ และแสดงข้อความ "ยอดชำระไม่ครบงวด — งวดที่ 3 ต้องชำระเต็มจำนวน {ยอดงวด} บาท ระบบไม่รับชำระบางส่วน" · งวดที่ 3 ยังมีสถานะ "ค้าง" และยอดคงเหลือของบัญชีไม่เปลี่ยน — ขาดแม้สตางค์เดียวก็ไม่ผ่าน ไม่มีค่าผ่อนผัน (tolerance)

## พิสูจน์กฎ

- [BR-miniloan-019@v1](../rules/BR-miniloan-019@v1.md) ✅ ปัจจุบัน — ไม่รับชำระบางส่วน — ชำระน้อยกว่ายอดงวด ระบบต้องแจ้งว่าไม่ครบงวด และไม่ปิดงวดนั้น
