# EX-miniloan-066

## กำหนดให้ (given)
ใบสมัครใบเดียวกันที่มอบหมายให้ ก. อยู่ และผู้ที่ล็อกอินอยู่คือ Loan Officer ชื่อ ข. ซึ่งมีสิทธิ์ระดับเดียวกับ ก. ทุกประการ

## เมื่อ (when)
ข. กดอนุมัติใบสมัครนั้น ทั้งจากหน้าจอและด้วยการเรียก API ตรง

## แล้ว (then)
ทั้งสองทางถูกปฏิเสธ — "อนุมัติไม่ได้ — ใบสมัครนี้มอบหมายให้ ก. เป็นผู้พิจารณา" · **มีสิทธิ์ระดับเดียวกันไม่พอ ต้องเป็นคนที่ถูกมอบหมายเท่านั้น**

## พิสูจน์กฎ

- [BR-miniloan-032@v1](../rules/BR-miniloan-032@v1.md) ✅ ปัจจุบัน — ใบสมัครที่เข้าสู่การพิจารณาต้องถูกมอบหมาย (assign) ให้ Loan Officer หนึ่งคน โดย**หัวหน้าเป็นผู้สั่งมอบหมาย** — ระบบไม่กระจายงานเอง และเจ้าหน้าที่หยิบงานเองไม่ได้ · เฉพาะคนที่ถูกมอบหมายเท่านั้นที่กดอนุมัติหรือปฏิเสธใบสมัครนั้นได้ Loan Officer คนอื่นทำไม่ได้แม้จะมีสิทธิ์ระดับเดียวกัน · ใบสมัครที่ยังไม่ถูกมอบหมายจึงอนุมัติหรือปฏิเสธไม่ได้เลย ต้องรอหัวหน้าจ่ายงานก่อน
