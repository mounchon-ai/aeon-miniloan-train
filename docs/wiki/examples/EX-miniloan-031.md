# EX-miniloan-031

## กำหนดให้ (given)
ใบสมัครที่อยู่ในสถานะ Submitted แล้ว — ขอบที่ตรวจคือสถานะหลังการล็อก ซึ่งเป็นสถานะที่ไม่มีเส้นกลับไปแก้ไข

## เมื่อ (when)
พยายามแก้จำนวนเงินกู้ของใบสมัครนั้น ทั้งจากหน้าจอและด้วยการเรียก API แก้ใบสมัครด้วย id เดิม

## แล้ว (then)
ทั้งสองทางถูกปฏิเสธเหมือนกัน — "ใบสมัครนี้ยื่นแล้ว แก้ไขข้อมูลไม่ได้" และ API ปฏิเสธด้วยตาม BR-miniloan-025@v1 · จำนวนเงินกู้ยังเป็นค่าเดิม

## พิสูจน์กฎ

- [BR-miniloan-007@v1](../rules/BR-miniloan-007@v1.md) ✅ ปัจจุบัน — ยื่นใบสมัครได้เฉพาะเมื่อกรอกครบ (ชื่อ อายุ รายได้ อายุงาน จำนวนเงินกู้ จำนวนงวด) — ครบแล้วสถานะเปลี่ยนเป็น Submitted และล็อกการแก้ไข · ไม่ครบ ระบบต้องปฏิเสธพร้อมระบุ field ที่ขาด และคงสถานะ Draft
