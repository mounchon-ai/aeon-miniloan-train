# EX-miniloan-082

## กำหนดให้ (given)
สถานการณ์เดียวกันที่ยังไม่มี role ผู้อนุมัติ — ขอบที่ตรวจคือทางเลี่ยงที่คนมักคิดถึง คือให้การแก้มีผลไปก่อนแล้วค่อยหาคนอนุมัติย้อนหลัง

## เมื่อ (when)
ก. เรียก API แก้ไขบัญชีที่ปิดแล้วโดยตรง โดยตั้งใจจะขออนุมัติย้อนหลังภายหลัง

## แล้ว (then)
API ปฏิเสธ — "ยังไม่ได้ตั้ง role ผู้อนุมัติ — การแก้ไขมีผลก่อนได้รับอนุมัติไม่ได้ทุกกรณี" ตาม BR-miniloan-025@v1 · ไม่มีการเขียนค่าใหม่ลงบัญชี และไม่มีรายการปรับปรุงถูกสร้างค้างไว้ — ระบบไม่มีสถานะ "แก้แล้วรออนุมัติย้อนหลัง" ให้เดินเข้าไปได้เลย

## พิสูจน์กฎ

- [BR-miniloan-040@v1](../rules/BR-miniloan-040@v1.md) ✅ ปัจจุบัน — ถ้ายังไม่ได้ตั้ง role ผู้อนุมัติตาม BR-miniloan-039@v1 ระบบต้องปฏิเสธคำขอปรับปรุงบัญชีที่ปิดแล้วทุกกรณีพร้อมแจ้งเหตุผล — ไม่มีผู้อนุมัติค่าเริ่มต้น (default) และห้ามให้การแก้มีผลไปก่อนแล้วค่อยหาคนอนุมัติทีหลัง
