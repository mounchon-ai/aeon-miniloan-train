# EX-miniloan-126

## กำหนดให้ (given)
หน้าจอเว็บที่ปกติตรวจช่วงจำนวนเงินให้ก่อนส่ง — จำลองว่าการตรวจฝั่งหน้าจอถูกข้ามไป

## เมื่อ (when)
ส่งข้อมูลชุดเดิม (5,000 บาท) ผ่านหน้าจอที่ปิดการตรวจแล้ว

## แล้ว (then)
**API ยังปฏิเสธเหมือนเดิมด้วยรหัสและข้อความเดียวกัน** · หน้าจอแสดงข้อความที่ API ส่งกลับมา ไม่ใช่ข้อความที่หน้าจอแต่งเอง · **การตรวจของหน้าจอเป็นความสะดวก ไม่ใช่ด่านสุดท้าย**

## พิสูจน์กฎ

- [BR-miniloan-026@v1](../rules/BR-miniloan-026@v1.md) ✅ ปัจจุบัน — เรียก API ด้วยข้อมูลที่ผิด business rule → API ต้องปฏิเสธพร้อมรหัสและข้อความ error ที่ชัดเจน โดยไม่พึ่งการ validate ของ Web เพียงอย่างเดียว
