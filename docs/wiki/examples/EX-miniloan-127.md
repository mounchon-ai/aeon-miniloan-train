# EX-miniloan-127

## กำหนดให้ (given)
หน้าจอกรอกใบสมัครที่ต้องแสดงวงเงินอนุมัติสูงสุดจากรายได้ที่กรอก

## เมื่อ (when)
ผู้ใช้กรอกรายได้แล้วหน้าจอต้องแสดงวงเงินสูงสุด

## แล้ว (then)
**หน้าจอเรียก API เพื่อขอตัวเลขทุกครั้ง** ไม่ได้คูณ 5 เองในเบราว์เซอร์ · ตรวจได้จากการที่มีคำขอออกไปยัง API ทุกครั้งที่ตัวเลขเปลี่ยน · **ตัวเลขที่ผู้ใช้เห็นมาจากฝั่งเดียวกับที่จะใช้ตัดสินตอนอนุมัติจริง จึงไม่มีวันไม่ตรงกัน**
