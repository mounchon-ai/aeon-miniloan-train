# EX-miniloan-119

## กำหนดให้ (given)
บัญชีเดียวกัน และผู้ใช้ที่พยายามข้ามการตรวจของหน้าจอ

## เมื่อ (when)
เรียก API บันทึกการชำระด้วยยอดที่ทำให้ส่วนเกินมากกว่ายอดปิดบัญชี โดยไม่ผ่านหน้าจอ

## แล้ว (then)
API ปฏิเสธด้วยเหตุผลเดียวกัน — **การบังคับเกิดที่ฝั่ง API ตาม BR-miniloan-025@v1 ไม่ใช่แค่ปุ่มบนหน้าจอที่กดไม่ได้** · สถานะบัญชีและตารางผ่อนไม่ถูกแตะต้อง

## พิสูจน์กฎ

- [BR-miniloan-052@v1](../rules/BR-miniloan-052@v1.md) ❄️ — ถ้ายอดส่วนที่เกินมากกว่ายอดปิดบัญชีตาม BR-miniloan-022@v1 ระบบต้อง**ปฏิเสธการบันทึกทั้งรายการ** — ไม่บันทึกการชำระ ไม่ปิดงวด ไม่ตัดเงินต้น ไม่ออกตารางผ่อนฉบับใหม่ และไม่ปิดบัญชี · ต้องแจ้ง Operations พร้อมยอดปิดบัญชีที่ถูกต้อง เพื่อบันทึกใหม่ด้วยยอดที่ทำให้ส่วนเกินเท่ากับยอดปิดบัญชีพอดี · **ไม่มีการทอนคืนและไม่มียอดค้างของผู้สมัครเก็บไว้ในระบบ** — เงินส่วนที่จ่ายเกินไปจริงถูกจัดการนอกระบบ ตามกรอบที่ตกลงไว้ว่าระบบบันทึกผลของการชำระที่เกิดขึ้นข้างนอกไปแล้ว ไม่ใช่ระบบรับเงินเอง · ผลที่ยอมรับแล้วคือระเบียนในระบบจะไม่ตรงกับเงินที่เคลื่อนจริงในกรณีนี้ จนกว่า Operations จะบันทึกใหม่ให้พอดี · ข้อจำกัดนี้ต้องบังคับที่ฝั่ง API ตาม BR-miniloan-025@v1 ไม่ใช่แค่กันที่หน้าจอ
