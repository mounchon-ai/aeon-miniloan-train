# EX-miniloan-138

## กำหนดให้ (given)
ระบบที่มีใบสมัครของหลายคนปนกันอยู่ในตารางเดียวกัน — ขอบที่ตรวจคือ **การเรียกดูแบบรายการ ไม่ใช่รายใบ**

## เมื่อ (when)
ก. เรียก API ขอรายการใบสมัครทั้งหมดที่ตัวเองเข้าถึงได้

## แล้ว (then)
**ไม่มีใบของคนอื่นหลุดเข้ามาแม้แต่ใบเดียว** และจำนวนรายการที่ได้ตรงกับจำนวนใบของ ก. เท่านั้น · **ช่องโหว่ของขอบเขตข้อมูลมักอยู่ที่การเรียกแบบรายการ ไม่ใช่รายใบ** เพราะรายใบมักมีการตรวจ แต่รายการมักลืม

## พิสูจน์กฎ

- [BR-miniloan-033@v1](../rules/BR-miniloan-033@v1.md) ✅ ปัจจุบัน — Applicant เห็นและเรียกดูได้เฉพาะใบสมัครและบัญชีสินเชื่อที่ตัวเองเป็นเจ้าของเท่านั้น · ขอบเขตนี้ต้องถูกบังคับที่ฝั่ง API ไม่ใช่แค่ซ่อนบนหน้าจอ — เรียก API ด้วย id ของคนอื่นต้องถูกปฏิเสธ
