# EX-miniloan-129

## กำหนดให้ (given)
ระบบที่ API ถูกปิดให้บริการอยู่ ส่วนเว็บยังทำงานปกติ

## เมื่อ (when)
ผู้ใช้เปิดหน้ารายการใบสมัคร

## แล้ว (then)
หน้าจอ **แสดงสถานะข้อผิดพลาดอย่างชัดเจน** — **"ตอนนี้เชื่อมต่อระบบไม่ได้ กรุณาลองใหม่อีกครั้ง"** · **ไม่ใช่หน้าขาว ไม่ใช่หน้าที่ค้างหมุนตลอด และไม่ใช่ข้อความภาษาอังกฤษดิบจากเบราว์เซอร์** · เมนูและส่วนอื่นของหน้ายังกดได้ ไม่พังทั้งแอป

## พิสูจน์กฎ

- [BR-miniloan-028@v1](../rules/BR-miniloan-028@v1.md) ✅ ปัจจุบัน — เมื่อ API ปิดให้บริการ Web ต้องแสดงสถานะข้อผิดพลาดอย่างเหมาะสม และต้องไม่ crash
