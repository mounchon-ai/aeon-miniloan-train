# EX-miniloan-125

## กำหนดให้ (given)
ข้อมูลใบสมัครที่มีจำนวนเงินกู้ที่ขอ 5,000 บาท ซึ่งต่ำกว่าขั้นต่ำ 10,000 บาทตาม BR-miniloan-004@v1

## เมื่อ (when)
เรียก API สร้างใบสมัครด้วยข้อมูลชุดนั้นโดยตรง

## แล้ว (then)
API ปฏิเสธพร้อม **รหัสข้อผิดพลาดที่อ่านได้ด้วยเครื่อง** และ **ข้อความไทยที่คนอ่านรู้เรื่อง** — **"จำนวนเงินกู้ที่ขอต้องอยู่ระหว่าง 10,000 – 1,000,000 บาท"** · **ไม่ใช่ข้อความว่างเปล่า ไม่ใช่ 500 Internal Server Error และไม่ใช่รหัสอย่างเดียวโดยไม่มีข้อความ**

## พิสูจน์กฎ

- [BR-miniloan-026@v1](../rules/BR-miniloan-026@v1.md) ✅ ปัจจุบัน — เรียก API ด้วยข้อมูลที่ผิด business rule → API ต้องปฏิเสธพร้อมรหัสและข้อความ error ที่ชัดเจน โดยไม่พึ่งการ validate ของ Web เพียงอย่างเดียว
