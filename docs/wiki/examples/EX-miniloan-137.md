# EX-miniloan-137

## กำหนดให้ (given)
ผู้สมัคร ก. ที่ล็อกอินอยู่ และเลขที่ใบสมัครของผู้สมัคร ข.

## เมื่อ (when)
ก. เรียก API เปิดดูใบสมัครของ ข. ด้วย id ของ ข. โดยตรง ไม่ผ่านหน้าจอ

## แล้ว (then)
API ปฏิเสธ — **"ไม่มีสิทธิ์เข้าถึงใบสมัครนี้"** · **การปฏิเสธเกิดที่ฝั่ง API ไม่ใช่แค่ไม่แสดงลิงก์บนหน้าจอ** — ถ้ากันแค่บนหน้าจอ ใบนี้จะผ่าน

## พิสูจน์กฎ

- [BR-miniloan-033@v1](../rules/BR-miniloan-033@v1.md) ✅ ปัจจุบัน — Applicant เห็นและเรียกดูได้เฉพาะใบสมัครและบัญชีสินเชื่อที่ตัวเองเป็นเจ้าของเท่านั้น · ขอบเขตนี้ต้องถูกบังคับที่ฝั่ง API ไม่ใช่แค่ซ่อนบนหน้าจอ — เรียก API ด้วย id ของคนอื่นต้องถูกปฏิเสธ
