# EX-miniloan-073

## กำหนดให้ (given)
ต่อจากสถานการณ์ที่ ก. ขอยอดปิดบัญชีก่อนกำหนดสำเร็จและเห็นยอดรวมบนหน้าจอแล้ว — ขอบที่ตรวจคือเส้นแบ่งระหว่างสิ่งที่ Applicant ทำได้กับสิ่งที่ทำไม่ได้ ซึ่งอยู่ติดกันบนหน้าจอเดียวกัน

## เมื่อ (when)
ก. กด "ยืนยันปิดบัญชี" ต่อจากหน้ายอดนั้น และเมื่อไม่สำเร็จก็เรียก API ปิดบัญชีด้วย id บัญชีของตัวเองโดยตรง

## แล้ว (then)
ทั้งสองทางถูกปฏิเสธ — หน้าจอแสดง "ขอยอดได้ แต่ปิดบัญชีเองไม่ได้ — นำยอดนี้ไปชำระ แล้วเจ้าหน้าที่ Operations จะเป็นผู้บันทึกการชำระและปิดบัญชีให้" และ API ปฏิเสธด้วยข้อความ "ไม่มีสิทธิ์ปิดบัญชีสินเชื่อ" ตาม BR-miniloan-025@v1 · บัญชียังคงสถานะ "กำลังผ่อนชำระ (Active)" และงวดที่เหลือในตารางผ่อนไม่ถูกยกเลิก

## พิสูจน์กฎ

- [BR-miniloan-034@v1](../rules/BR-miniloan-034@v1.md) ✅ ปัจจุบัน — บันทึก Payment และปิดบัญชีสินเชื่อทำได้เฉพาะ Operations · Applicant ขอยอดปิดบัญชีก่อนกำหนดได้ แต่บันทึกการชำระเองและปิดบัญชีเองไม่ได้
