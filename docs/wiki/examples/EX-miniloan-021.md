# EX-miniloan-021

## กำหนดให้ (given)
ผู้สมัครที่มีรายได้ 200,000 บาทต่อเดือน — ห้าเท่าได้ 1,000,000 บาทพอดี เท่ากับเพดานพอดี เป็นจุดที่สองเงื่อนไขให้คำตอบเดียวกัน

## เมื่อ (when)
ระบบประเมินและคำนวณวงเงินอนุมัติสูงสุด

## แล้ว (then)
หน้าผลการประเมินแสดง "วงเงินที่อนุมัติได้ 1,000,000 บาท" — จุดนี้คือรอยต่อที่สูตรกับเพดานให้คำตอบตรงกัน โค้ดที่เขียนเงื่อนไขผิดด้าน (ใช้ < แทน ≤ หรือกลับกัน) จะพลาดที่ค่านี้ค่าเดียว

## พิสูจน์กฎ

- [BR-miniloan-003@v1](../rules/BR-miniloan-003@v1.md) ✅ ปัจจุบัน — วงเงินอนุมัติสูงสุด = 5 เท่าของรายได้ต่อเดือน และไม่เกิน 1,000,000 บาท
