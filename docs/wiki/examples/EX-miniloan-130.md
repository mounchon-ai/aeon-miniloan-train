# EX-miniloan-130

## กำหนดให้ (given)
หน้าเดียวกันที่เพิ่งแสดงข้อผิดพลาดไป และ API เพิ่งกลับมาให้บริการ — ขอบที่ตรวจคือจังหวะฟื้นตัว

## เมื่อ (when)
ผู้ใช้กดปุ่มลองใหม่บนหน้าเดิม

## แล้ว (then)
หน้าจอโหลดข้อมูลได้ตามปกติทันที · **ไม่ต้องปิดแล้วเปิดแอปใหม่ ไม่ต้องล็อกอินใหม่** · สถานะข้อผิดพลาดหายไปเอง — พิสูจน์ว่าหน้าจอไม่ได้พังค้างอยู่ แค่แสดงสถานะ

## พิสูจน์กฎ
