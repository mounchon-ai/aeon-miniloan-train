# EX-miniloan-124

## กำหนดให้ (given)
ใบสมัครเดียวกัน และผู้ใช้ที่เป็น Loan Officer ข. ซึ่งไม่ได้ถูกมอบหมายใบนี้

## เมื่อ (when)
ข. เรียก API อนุมัติใบสมัครนั้นโดยตรง

## แล้ว (then)
API ปฏิเสธ — **"อนุมัติไม่ได้ — ใบสมัครนี้มอบหมายให้ผู้พิจารณาคนอื่น"** · **กฎธุรกิจถูกบังคับที่ฝั่ง API ไม่ใช่แค่ที่หน้าจอ** — ถ้าปฏิเสธเฉพาะบนหน้าจอ ใบนี้จะผ่าน และนั่นคือสิ่งที่กฎข้อนี้ห้าม
