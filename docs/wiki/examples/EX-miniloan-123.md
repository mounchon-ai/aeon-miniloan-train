# EX-miniloan-123

## กำหนดให้ (given)
ใบสมัครสถานะ "อยู่ระหว่างพิจารณา (UnderReview)" ที่ถูกมอบหมายให้ Loan Officer ก. แล้ว — ใช้ความสามารถ "อนุมัติใบสมัคร" เป็นตัวแทนของ Epic 1–8

## เมื่อ (when)
ก. เรียก API อนุมัติใบสมัครนั้นโดยตรง ไม่ผ่านหน้าจอเลย

## แล้ว (then)
**มี endpoint รองรับจริงและทำงานได้ครบ** — ใบสมัครเปลี่ยนเป็น "อนุมัติแล้ว (Approved)" พร้อมบันทึกผู้อนุมัติและเวลา เหมือนกับที่กดผ่านหน้าจอทุกประการ · **ใบนี้พิสูจน์ความสามารถหนึ่งตัวเป็นตัวแทน ไม่ได้พิสูจน์ทุกความสามารถใน Epic 1–8 พร้อมกัน** — ความครบถ้วนต้องมาจากการที่ทุกกฎมีตัวอย่างของตัวเอง

## พิสูจน์กฎ
