# EX-miniloan-084

## กำหนดให้ (given)
ระบบเดียวกัน · ผู้ใช้ที่ล็อกอินมีบทบาท Operations ซึ่งเป็นฝ่ายที่มักเป็นผู้ขอแก้เอง

## เมื่อ (when)
Operations พยายามเปิดหน้าตั้งค่า role ผู้อนุมัติและกำหนดค่าเอง ทั้งจากหน้าจอและด้วยการเรียก API ตั้งค่าโดยตรง (ทดสอบด้วยบทบาท Applicant ให้ผลเดียวกัน)

## แล้ว (then)
ทั้งสองทางถูกปฏิเสธ — เมนูตั้งค่า role ผู้อนุมัติไม่ปรากฏสำหรับบทบาทนี้ และ API ปฏิเสธด้วยข้อความ "ไม่มีสิทธิ์ตั้งค่า role ผู้อนุมัติ — ทำได้เฉพาะ Loan Officer" ตาม BR-miniloan-025@v1 · ค่า role ผู้อนุมัติไม่เปลี่ยน — ฝ่ายที่จะเป็นผู้ขอแก้ ตั้งผู้อนุมัติของตัวเองไม่ได้

## พิสูจน์กฎ

- [BR-miniloan-048@v1](../rules/BR-miniloan-048@v1.md) ✅ ปัจจุบัน — ผู้มีสิทธิ์ตั้งค่าและเปลี่ยน role ผู้อนุมัติตาม BR-miniloan-039@v1 คือ Loan Officer เท่านั้น — Operations และ Applicant ตั้งค่าไม่ได้ ทั้งจากหน้าจอและผ่าน API · โมดูลนี้ไม่เพิ่ม actor ผู้ดูแลระบบ (System Admin) เข้ามาในรอบนี้
