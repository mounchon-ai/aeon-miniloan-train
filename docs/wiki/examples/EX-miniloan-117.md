# EX-miniloan-117

## กำหนดให้ (given)
บัญชีสถานะ Active ที่มียอดปิดบัญชีตาม BR-miniloan-022@v1 เท่ากับ 50,700.00 บาท

## เมื่อ (when)
Operations บันทึกการชำระที่ทำให้ส่วนเกินเท่ากับ 55,000.00 บาท ซึ่งมากกว่ายอดปิดบัญชีอยู่ 4,300.00 บาท

## แล้ว (then)
ระบบ **ปฏิเสธการบันทึกทั้งรายการ** — ไม่บันทึกการชำระ ไม่ปิดงวด ไม่ตัดเงินต้น ไม่ออกตารางผ่อนฉบับใหม่ และไม่ปิดบัญชี · แจ้ง **"บันทึกไม่ได้ — ยอดชำระเกินยอดปิดบัญชี 4,300.00 บาท · ยอดปิดบัญชีที่ถูกต้องคือ 50,700.00 บาท กรุณาบันทึกใหม่ให้พอดี"** · **ไม่มีการทอนคืนและไม่มียอดค้างของผู้สมัครเก็บไว้ในระบบ** — เงินส่วนที่จ่ายเกินไปจริงจัดการนอกระบบ

## พิสูจน์กฎ

- [BR-miniloan-052@v1](../rules/BR-miniloan-052@v1.md) ✅ ปัจจุบัน — ถ้ายอดส่วนที่เกินมากกว่ายอดปิดบัญชีตาม BR-miniloan-022@v1 ระบบต้อง**ปฏิเสธการบันทึกทั้งรายการ** — ไม่บันทึกการชำระ ไม่ปิดงวด ไม่ตัดเงินต้น ไม่ออกตารางผ่อนฉบับใหม่ และไม่ปิดบัญชี · ต้องแจ้ง Operations พร้อมยอดปิดบัญชีที่ถูกต้อง เพื่อบันทึกใหม่ด้วยยอดที่ทำให้ส่วนเกินเท่ากับยอดปิดบัญชีพอดี · **ไม่มีการทอนคืนและไม่มียอดค้างของผู้สมัครเก็บไว้ในระบบ** — เงินส่วนที่จ่ายเกินไปจริงถูกจัดการนอกระบบ ตามกรอบที่ตกลงไว้ว่าระบบบันทึกผลของการชำระที่เกิดขึ้นข้างนอกไปแล้ว ไม่ใช่ระบบรับเงินเอง · ผลที่ยอมรับแล้วคือระเบียนในระบบจะไม่ตรงกับเงินที่เคลื่อนจริงในกรณีนี้ จนกว่า Operations จะบันทึกใหม่ให้พอดี · ข้อจำกัดนี้ต้องบังคับที่ฝั่ง API ตาม BR-miniloan-025@v1 ไม่ใช่แค่กันที่หน้าจอ
