# EX-miniloan-042

## กำหนดให้ (given)
ผู้สมัครที่ผ่านเกณฑ์คุณสมบัติทุกข้อ มีรายได้ 30,000 บาทต่อเดือน และภาระหนี้รวม 15,000 บาทพอดี — DTI เท่ากับ 50% พอดี ซึ่งเป็นขอบที่ Q-miniloan-003 เพิ่งตัดสิน

## เมื่อ (when)
ยื่นใบสมัคร และระบบประเมินอัตโนมัติ

## แล้ว (then)
หน้าผลการประเมินแสดง "Credit Band A — อนุมัติอัตโนมัติได้ (รอเจ้าหน้าที่ยืนยัน)" · **DTI 50% พอดีได้ Band A ไม่ใช่ Band B** — ขอบนี้นับรวมเข้าฝั่ง A

## พิสูจน์กฎ

- [BR-miniloan-006@v1](../rules/BR-miniloan-006@v1.md) ✅ ปัจจุบัน — จัด Credit Band จากผลประเมิน: Band A = ผ่านทุกเกณฑ์ + DTI ≤ 50% → อนุมัติอัตโนมัติได้ (ยังต้องให้เจ้าหน้าที่ยืนยัน) · Band B = ผ่านเกณฑ์ + DTI มากกว่า 50% ถึง 70% → ส่งเจ้าหน้าที่พิจารณา · Band C = ผิดเกณฑ์ข้อใดข้อหนึ่ง → ปฏิเสธพร้อมเหตุผล · DTI เท่ากับ 50% พอดีได้ Band A ไม่ใช่ Band B — ขอบทั้งสองแบนด์ไม่ซ้อนกันอีกต่อไป
