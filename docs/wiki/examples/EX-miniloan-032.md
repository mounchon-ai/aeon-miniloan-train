# EX-miniloan-032

## กำหนดให้ (given)
ผู้สมัครเปิดหน้าใบสมัครใหม่ กรอกเฉพาะชื่อ แล้วยังไม่ได้กรอกช่องอื่นเลย

## เมื่อ (when)
กด "บันทึกร่าง"

## แล้ว (then)
ระบบบันทึกสำเร็จและแสดง "บันทึกร่างเรียบร้อย" · ได้ใบสมัครสถานะ "ร่าง (Draft)" ที่กลับมาแก้ต่อได้ · **ไม่มีข้อความเตือนเรื่องช่องที่ยังไม่ได้กรอก**

## พิสูจน์กฎ
