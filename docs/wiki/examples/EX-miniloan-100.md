# EX-miniloan-100

## กำหนดให้ (given)
ผู้สมัคร ก. ที่ล็อกอินอยู่ และเลขบัญชีสินเชื่อของผู้สมัคร ข. ซึ่งเป็นคนละคน

## เมื่อ (when)
ก. เรียกดูตารางผ่อนของบัญชี ข. ทั้งจากหน้าจอและด้วยการเรียก API ตรง

## แล้ว (then)
ทั้งสองทางถูกปฏิเสธ — **"ไม่มีสิทธิ์เข้าถึงบัญชีสินเชื่อนี้"** · การปฏิเสธเกิดที่ฝั่ง API ตาม BR-miniloan-033@v1 ไม่ใช่แค่ไม่แสดงลิงก์บนหน้าจอ · **ไม่มีข้อมูลงวดใดของ ข. หลุดออกมาแม้แต่แถวเดียว**

## พิสูจน์กฎ

- [BR-miniloan-018@v1](../rules/BR-miniloan-018@v1.md) ✅ ปัจจุบัน — เจ้าของบัญชีเปิดดูตารางผ่อนของบัญชีสถานะ Active ของตัวเองได้ทั้งตาราง พร้อมสถานะรายงวด (จ่ายแล้ว / ค้าง)
