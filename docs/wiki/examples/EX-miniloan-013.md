# EX-miniloan-013

## กำหนดให้ (given)
บัญชีสินเชื่อสถานะ Active เดียวกัน ที่งวดที่ 3 เป็นงวดค้าง — ขอบที่ตรวจคือค่าที่ตรงเส้นพอดี ซึ่งเป็นฝั่งที่ผ่าน

## เมื่อ (when)
Operations บันทึกการชำระงวดที่ 3 ด้วยยอดที่ตรงกับยอดงวดพอดี

## แล้ว (then)
ระบบบันทึกการชำระสำเร็จ และแสดงข้อความ "บันทึกการชำระงวดที่ 3 เรียบร้อย" · งวดที่ 3 เปลี่ยนสถานะเป็น "จ่ายแล้ว" และยอดคงเหลือของบัญชีลดลงตามเงินต้นของงวดนั้น ตาม BR-miniloan-020@v1

## พิสูจน์กฎ

- [BR-miniloan-020@v1](../rules/BR-miniloan-020@v1.md) ✅ ปัจจุบัน — บันทึก Payment ตรงตามยอดงวดของบัญชี Active ที่มีงวดค้าง → งวดนั้นเปลี่ยนสถานะเป็น Paid และยอดคงเหลือของบัญชีลดลง
