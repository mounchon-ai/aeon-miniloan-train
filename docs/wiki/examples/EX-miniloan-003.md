# EX-miniloan-003

## กำหนดให้ (given)
บัญชีสินเชื่อของผู้กู้ที่มีรายได้ 200,000 บาทต่อเดือน ซึ่งทำให้วงเงินสูงสุดตาม BR-miniloan-003@v1 ชนเพดาน 1,000,000 บาทพอดี · เบิกจ่ายเงินต้น 1,000,000 บาท ผ่อน 60 งวด — ทั้งเงินต้นและจำนวนงวดอยู่ที่ค่าสูงสุดที่ BR-miniloan-004@v1 ยอมรับ อัตราลดต้นลดดอก 25% ต่อปี · เป็นเคสที่เศษจากการปัดสะสมมากที่สุดในระบบ

## เมื่อ (when)
เปิดตารางผ่อนของบัญชีนั้น แล้วดูแถวสรุปท้ายตารางกับแถวงวดที่ 60

## แล้ว (then)
แถวสรุปแสดง "รวมเงินต้น 60 งวด 1,000,000.00 บาท — ตรงกับเงินต้นตั้งต้น" ไม่ใช่ "999,999.99" หรือ "1,000,000.03" และช่อง "ยอดคงเหลือ" ของงวดที่ 60 แสดง "0.00"

## พิสูจน์กฎ

- [BR-miniloan-017@v1](../rules/BR-miniloan-017@v1.md) ✅ ปัจจุบัน — ผลรวมเงินต้นทุกงวดในตารางผ่อนต้องเท่ากับเงินต้นตั้งต้นพอดี และยอดคงเหลือหลังงวดสุดท้ายต้องเป็น 0 — งวดสุดท้ายเป็นงวดที่รับเศษจากการปัด
