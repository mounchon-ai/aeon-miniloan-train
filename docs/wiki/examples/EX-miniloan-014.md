# EX-miniloan-014

## กำหนดให้ (given)
บัญชีสินเชื่อสถานะ Active เดียวกัน ที่งวดที่ 3 เป็นงวดค้าง และยังไม่มีการชำระงวดนั้นเลย

## เมื่อ (when)
Operations บันทึกการชำระงวดที่ 3 เป็นสองครั้ง ครั้งละครึ่งหนึ่งของยอดงวด ซึ่งรวมกันแล้วเท่ากับยอดงวดพอดี

## แล้ว (then)
ทั้งสองครั้งถูกปฏิเสธแยกกันด้วยข้อความเดียวกัน "ยอดชำระไม่ครบงวด — งวดที่ 3 ต้องชำระเต็มจำนวน {ยอดงวด} บาท ระบบไม่รับชำระบางส่วน" · ไม่มีการสะสมยอดที่จ่ายมาก่อนหน้า และไม่มีสถานะ "ชำระแล้วบางส่วน" ในระบบ · งวดที่ 3 ยังเป็น "ค้าง" และยอดคงเหลือของบัญชีไม่เปลี่ยน

## พิสูจน์กฎ

- [BR-miniloan-019@v1](../rules/BR-miniloan-019@v1.md) ✅ ปัจจุบัน — ไม่รับชำระบางส่วน — ชำระน้อยกว่ายอดงวด ระบบต้องแจ้งว่าไม่ครบงวด และไม่ปิดงวดนั้น
